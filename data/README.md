# Данные разработки

`local/` — место локальных наборов, эталонов и рабочих копий; содержимое не входит
в Git. Исходные материалы организаторов сейчас остаются в соседнем `task-dir/task-dir`.
Ничего из них не скопировано. Будущие прогоны не меняют оригиналы: каждый запуск
получает свежую копию задачи, чтобы не переиспользовать исправленный код и ответы.

В Git допустимы небольшие собственные фикстуры в `tests/fixtures/` и проверенные
манифесты/описания происхождения. Для набора фиксировать источник, лицензию,
семейство задачи, версию, разделение development/holdout и способ получения эталона.
Близкие варианты шаблона остаются в одной группе разделения.

`expected` и другие метки оценки принадлежат внешнему оценщику. Их нельзя отдавать
решателю через манифест, инструменты чтения, оценщик стоимости или промпт.
