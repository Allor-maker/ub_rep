# Эксперименты

Ответственные: A — выбор и стоимость, B — качество решений. Эксперименты ещё
не запускались. Содержимое `runs/` локальное и игнорируется Git.

Будущий отчёт должен содержать: гипотезу, commit, конфигурацию и модель, версию
набора и разбиение, бюджет/время/параллельность, сумму наград, правильные решения,
usage входа/выхода/reasoning, затраты на неудачи, причины остановок и ограничения.
Оборванная попытка отдельно отмечается: её расход не равен полной цене решения.

Сравнивать одинаковые наборы, бюджеты и награды, отдельно проверять holdout.
Один отчёт отвечает на один вопрос: маршрут, контекст, повтор или модель.
Не принимать улучшение только по восьми учебным примерам или единственному удачному
прогону. Сырые промпты/ответы, заголовки запросов и ключи в Git не попадают.

Малые обезличенные итоговые отчёты можно добавлять сюда после review.
Живые API-прогоны отделены от обычных тестов. Допустимость хранения траекторий
и обучения классического оценщика выясняется по Q6 до соответствующих действий.
