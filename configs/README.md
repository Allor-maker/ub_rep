# Конфигурации

Владелец: A, изменения параметров экспериментов рецензирует B.

Здесь появятся только конфигурации с реализованной схемой и проверенными значениями.
Сейчас нет YAML с выдуманным бюджетом, лимитом reasoning или адресом прокси.
Версионируются профили без секретов; `*.local.*` игнорируются.

Будущие группы настроек: разрешённые решатели/инструменты, ограничения попытки,
политика отбора, параллельность и безопасные параметры журналирования. Способ
передачи конкурсного бюджета определяется ответом Q1. Ключ и адрес финального
прокси поступают из окружения. Данные задач не могут менять эту конфигурацию.
