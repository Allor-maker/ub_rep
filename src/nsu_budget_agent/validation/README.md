# Проверки, доступные агенту — B

Проверка формата и свидетельств, запуск разрешённых тестов без эталонных ответов.
Возвращает passed/failed/inconclusive и ограничения проверки. Не импортирует
внешний evaluation, не объявляет видимые тесты эквивалентом скрытых и не публикует
ответ самостоятельно. Новые виды проверки добавляются без изменения планировщика.
