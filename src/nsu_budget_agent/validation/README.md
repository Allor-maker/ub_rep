# Проверки, доступные агенту — B

`LocalValidator(tools)` проверяет обязательные format/paths/protected_files/snapshot,
целостность evidence и отсутствие исходных изменений. Семантика заново вычисляется
production-инструментами из публичного условия и проверочной копии A5; неправильная
непустая строка не проходит. Неподдержанные hints/условия и незавершённая обязательная
проверка блокируют сдачу. expected/gold/evaluation не используются, answer.txt
валидатор не создаёт. ОС-изолированные unittest недоступны и дают inconclusive.
Для CSV дополнительный blocking-аудит независимо считает order_id/строки и проверяет
полноту фильтров; он не использует общее вычислительное ядро решателя.

Риски общей грамматики solver/validator и охват: [B-minimal](../../../docs/b-minimal-report.md).
