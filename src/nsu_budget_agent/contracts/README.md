# Общие контракты — реализация A, review B

Источник истины: [Contracts v1](../../../docs/contracts.md).
`models.py` содержит DTO, алиасы и ошибки; `ports.py` — Protocol и SolverContext.
B импортирует эти определения. Зависимостей от SDK, решателей и транспорта нет.

Сырые строки путей передавайте в `parse_rel_path` до создания PurePosixPath:
последний нормализует `./` и пустые сегменты, скрывая некорректный исходный ввод.
DTO дополнительно проверяют уже типизированные пути. ФС/состояние процесса
проверяют реализации портов. JSON хранится как неизменяемый текстовый снимок;
каждое чтение JSON-поля возвращает отдельное обычное dict/list-представление.
Его изменение не меняет DTO. Для нескольких операций сохраните представление
в локальную переменную; для нового значения создайте новый DTO.
`json.dumps`, `dataclasses.asdict`, deepcopy и pickle поддерживаются.
