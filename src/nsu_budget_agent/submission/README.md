# Публикация результатов — A

Единая точка записи принятого ответа и фиксации необходимых изменённых артефактов.
Возвращает подтверждение записи, а не утверждение о скрытой корректности.
Атомарное сохранение после каждой задачи. Место answer.txt и роль OUT уточняются
через Q2; изменение этого контракта не должно затрагивать каждый решатель.
