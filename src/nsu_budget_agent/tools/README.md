# Инструменты — B

`LocalToolExecutor` реализует неизменный ToolExecutor: `read_file`, `local_math`,
`query_csv`, `audit_csv`, `lookup_markdown`. Только разрешённый staging, UTF-8 текст/Markdown/CSV,
проверка SHA-256/размера, лимиты чтения/вывода/времени, no-follow открытия A4.
expected/gold/служебные пути запрещены. Ошибка/неполные данные дают ToolResult.error,
а не случайно усечённый ответ. Каталог не предоставляет shell, exec, запись,
HTTP или запуск пользовательского Python. Разрешены только ограниченные алгоритмы
точной арифметики, агрегации и поиска по явным атрибутам.
Заказы считаются по различным явно объявленным непустым order_id, строки — отдельной
операцией; пустые фильтры/неоднозначные идентификаторы приводят к отказу.

Охват и границы: [B-minimal](../../../docs/b-minimal-report.md).
