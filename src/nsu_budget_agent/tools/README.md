# Инструменты — B

Чтение и поиск, читатели новых форматов, вычисления, применение правок и запуск
проверок. Вход и выход структурированы; пути, время и объём вывода ограничены.
Без прямого LLM-доступа и без чтения эталонов. Неизвестный формат возвращает
явный результат. Локальный процесс не считается полноценной изоляцией произвольного кода.
