# Бюджет — A

Единое состояние: расход, активные резервы, неопределённые списания и остаток.
Выдаёт lease перед каждым запросом, учитывает usage идемпотентно. Единица хранения
— десятая бюджетного токена (Units в Contracts v1). Reasoning учитывается ровно один раз.
Прогноз планировщика не заменяет резерв; timeout не доказывает бесплатность вызова.
