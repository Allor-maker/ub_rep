# LLM-шлюз — A

Единственная точка общения с разрешённым прокси. Использует бюджетный контроллер,
нормализует usage, ошибки и отмену; все повторы видимы и ограничены. Адрес и ключ
из окружения. Решатели и инструменты не создают собственных сетевых клиентов.
Версии транспорта и точные возможности финального прокси пока не подтверждены.
