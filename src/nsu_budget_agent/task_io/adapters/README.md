# Входные адаптеры — A, требования читателей согласуются с B

Первый будущий адаптер поддержит манифест организаторов. Следующий формат
добавляется отдельным модулем с контрактными тестами. Планировщик получает
нормализованный TaskSpec и не знает устройство конкретного манифеста.
Это место реализации, без динамической загрузки кода из входной задачи.
