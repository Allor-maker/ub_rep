# Вход задач — A

Обнаружение задач и перевод внешнего формата в общий TaskSpec. Раздельные корни
задачи и рабочего каталога; артефакты доступны по ссылкам, без загрузки всех данных
в промпт. Реализация входных форматов располагается в `adapters/`.
Сырой манифест и эталоны не передаются решателю. Неизвестный формат диагностируется.
