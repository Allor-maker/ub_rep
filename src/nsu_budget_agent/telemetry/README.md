# События и расход — A

Структурированные события попыток, запросов, инструментов, остановок и публикаций.
Запросы имеют ID для сверки usage; секреты, заголовки авторизации и эталонные ответы
не журналируются. Ограничивать объём и писать только в разрешённое место.
Формат и путь согласуются с B для внешней оценки, без обязательного удалённого сервиса.

В A3 добавлен `LLMEvent`: локальные ID запроса/попытки, модель, фаза и статус usage/
код ошибки. Gateway передаёт его необязательному синхронному sink; обычный сбой sink
не меняет учёт расхода. Prompt, response, reasoning, URL и ключ в event отсутствуют.
Файловый/удалённый журнал и события orchestration относятся к следующим этапам.
