# Внешняя оценка (B)

Здесь появятся оценщик правильности, подготовка независимых запусков и сравнение
конфигураций. Это код разработки, не часть runtime-решателя.

Оценщик может читать эталоны и скрытые для агента проверки, но не передаёт их
в `TaskSpec`, инструменты или контекст. Модули из `src/nsu_budget_agent/` не
импортируют `evaluation/`. Эталоны и приватные наборы не включаются в runtime-образ.

Вход будущего оценщика: исходный набор, отдельно эталонные данные, сохранённые
результаты и usage. Выход: награда, правильность, стоимость, время и причины ошибок.
Восемь примеров служат smoke-набором; самостоятельная проверка требует новых
семейств, неизвестных типов и разнообразных структур данных. Реализации пока нет.
